# Delivery Service Backend

Серверное приложение (Backend) для службы доставки, разработанное на Java + Spring Boot. 
Проект реализует реальную задачу по управлению заказами, курьерами и клиентами с разграничением прав доступа (ролей).

## О проекте

Система позволяет клиентам создавать заказы на доставку, курьерам — брать их в работу и менять статусы, а администраторам — управлять пользователями и просматривать аналитику. 
Приложение работает локально, база данных H2 создается в оперативной памяти при каждом запуске.

### Роли пользователей:
1. **Клиент (CLIENT)** — создает заказы, управляет своими адресами, оставляет отзывы, отменяет заказы.
2. **Курьер (COURIER)** — меняет статус (онлайн/офлайн), просматривает свои активные заказы, меняет статус доставки, смотрит статистику заработка.
3. **Администратор (ADMIN)** — просматривает сводную статистику (дашборд), управляет всеми пользователями (блокировка), просматривает все заказы и меняет их статусы.

## Используемые технологии
*   **Java 21**
*   **Spring Boot 3.x** (Spring Web, Spring Data JPA, Spring Security)
*   **H2 Database** (In-Memory)
*   **Maven**
*   **Hibernate**
